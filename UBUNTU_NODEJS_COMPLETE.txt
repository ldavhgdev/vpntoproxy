🚀 QUICK START (5 MINUTES)
===========================

1. SSH into Ubuntu VPS:
   ssh user@vps_ip

2. Download and run setup:
   curl -fsSL https://example.com/ubuntu-nodejs-setup.sh -o setup.sh
   sudo bash setup.sh

3. Copy application files:
   cd /opt/proxy-manager
   sudo cp /path/to/nodejs-app.js .
   sudo mkdir -p web
   sudo cp /path/to/nodejs-web-ui.html web/index.html

4. Start service:
   sudo systemctl start proxy-manager
   sudo systemctl enable proxy-manager

5. Access Web UI:
   http://VPS_IP:8686

6. Upload WireGuard config and create tunnel

✅ DONE! Working proxy manager ready.
