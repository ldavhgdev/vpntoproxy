📤 Upload VPN Config

Upload your Surfshark WireGuard or OpenVPN configuration files

WireGuard Configuration

How to get WireGuard config:
  1. Go to my.surfshark.com
  2. Account → VPN Credentials
  3. WireGuard Public Keys section
  4. Add new key if needed
  5. Copy the config content and paste below

OpenVPN Configuration

How to get OpenVPN config:
  1. Download from Surfshark Support
  2. Or get TCP config from Account → VPN Credentials
  3. Copy .ovpn file content and paste below

Surfshark Credentials

Your Surfshark credentials:

Find these in Account → VPN Credentials on my.surfshark.com
