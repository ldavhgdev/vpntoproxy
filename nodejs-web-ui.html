Xuất danh sách proxy

GPM Login chạy cùng máy thì dùng 127.0.0.1. Máy khác trong LAN dùng IP LAN của máy này và bật "Cả mạng LAN" cho tunnel.

Cài đặt

Đổi cổng hoặc địa chỉ Web UI có hiệu lực sau khi khởi động lại ứng dụng. Mở Web UI ra LAN bắt buộc phải có mật khẩu (tên đăng nhập gõ gì cũng được).
